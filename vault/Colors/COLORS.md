# OptimityFX — Color Palette

Source of truth: `website/css/style.css` (`:root` tokens) on optimityfx.com.

## Core / Backgrounds (dark theme)
| Name | Hex | Usage |
|------|-----|-------|
| Black (base) | `#07090C` | Page background, also `theme-color` |
| BG-2 | `#0B0E13` | Secondary background |
| Panel | `#10141B` | Cards / panels |
| Panel-2 | `#141923` | Raised panels |
| Line | `#1E2430` | Borders |
| Line Soft | `#181D26` | Subtle borders / dividers |

## Text
| Name | Hex | Usage |
|------|-----|-------|
| White | `#FFFFFF` | Headings, high emphasis |
| Text | `#E7EAF0` | Default body text |
| Muted | `#9AA3B2` | Secondary text / paragraphs |
| Dim | `#5E6776` | Labels, captions |
| Faint | `#3A424F` | Lowest emphasis |

## Accent / Brand
| Name | Hex | Usage |
|------|-----|-------|
| Accent (signature cyan) | `#00D4FF` | Primary brand accent, links, glow |
| Accent-2 | `#1E90FF` | Secondary blue |
| FX Red | `#FF3B57` | Alerts, "FX" red accent |
| Red Soft | `#CC2222` | Muted red |

## Gradients
- **Spectrum:** `linear-gradient(90deg,#00D4FF,#3AA0FF,#7C7BFF,#3AA0FF,#00D4FF)`
- **Spectrum Soft:** `linear-gradient(90deg,#00D4FF,#4D9FFF,#9B86FF)`
- **Cool (primary buttons/brand):** `linear-gradient(135deg,#00D4FF 0%,#1E90FF 100%)`
- **Warm (FX logo mark):** `linear-gradient(135deg,#FF8A3D 0%,#FF3B57 100%)`
