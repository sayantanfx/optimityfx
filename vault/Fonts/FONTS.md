# OptimityFX — Fonts

The OptimityFX website uses a single typeface: **Inter**.

## Files in this folder
Static weights used across the site:
- `Inter-Light.ttf` (300)
- `Inter-Regular.ttf` (400)
- `Inter-Medium.ttf` (500)
- `Inter-SemiBold.ttf` (600)
- `Inter-Bold.ttf` (700)
- `Inter-ExtraBold.ttf` (800)
- `Inter-Black.ttf` (900)
- `InterVariable.ttf` — variable font (all weights in one file; best for design tools)
- `Inter-LICENSE.txt` / `LICENSE.txt` — SIL Open Font License 1.1 (free for commercial use)

## Install (macOS)
Double-click each `.ttf` → **Install Font**, or drop them into Font Book.

## On the web
Loaded from Google Fonts:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800;900&display=swap" rel="stylesheet">
```
