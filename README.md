# OptimityFX — Website

Premium multi-page creative-studio website. Static HTML/CSS/JS — no build step or dependencies required to run.

## Run locally

**Option A — just open it**
Double-click `index.html` (works in any modern browser).

**Option B — local server (recommended, avoids any file:// quirks)**
```bash
cd optimityfx-website
python3 -m http.server 4321
```
Then visit http://localhost:4321

> Fonts (Google Fonts) and the placeholder images (picsum.photos) load from the internet. Everything else runs fully offline.

## Pages
- `index.html` — Home
- `services.html` — Services
- `portfolio.html` — Work / portfolio (filters, before/after sliders)
- `academy.html` — NextGen Academy
- `store.html` — Digital store (LUTs, presets, templates, courses)
- `coaching.html` — Business coaching
- `about.html` — About + team
- `blog.html` / `blog-post.html` — Blog
- `contact.html` — Contact
- `app.html` — Mobile app listing (iOS / Android)
- `terms.html`, `privacy.html` — Legal

## Structure
```
css/style.css     Design system (single stylesheet for all pages)
js/main.js        Interactions (nav, reveals, sliders, lightbox, filters)
assets/           Logo + favicon
build.py          Optional generator that re-emits inner pages from a shared shell
manifest.json     PWA manifest
robots.txt, sitemap.xml
```

## Customize before launch
- Replace placeholder images (`picsum.photos/...`) with your real work.
- Swap the showreel embed URL in `index.html` (`.video-poster data-src`) for your YouTube/Vimeo.
- Update domain (`optimityfx.com`), social links, email/phone, team bios.
- Wire forms (`form[data-fake]`) to a backend (Formspree / your API) and the store to a payment gateway.

## Editing inner pages
`index.html` and `services.html` are hand-authored. The other inner pages are generated by `build.py`
(shared nav/footer + per-page body). Edit content in `build.py` then run `python3 build.py` to regenerate.
You can also just edit the generated `.html` files directly if you prefer.
